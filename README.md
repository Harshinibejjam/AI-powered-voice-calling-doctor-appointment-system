🏥 AI Voice Calling Doctor Appointment System

An AI-powered voice calling system that allows patients to book doctor appointments through a phone call without requiring a smartphone or web application.

## 🚀 Features

- 📞 Voice-based doctor appointment booking
- 🤖 AI-powered conversational assistant
- 🎙️ Speech-to-text using AssemblyAI
- 🔊 Text-to-speech using ElevenLabs
- 📱 Phone call handling with Twilio
- ⚡ Real-time audio streaming with WebSocket
- 🏥 Patient and appointment management
- 📊 Admin dashboard

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- Twilio
- AssemblyAI
- OpenAI
- ElevenLabs
- Appwrite
- WebSocket
